# Learning Approach

My approach is focused on **learning by building**.

For each topic, I aim to:

1. Understand the concept
2. Study practical examples
3. Write the concept myself
4. Build small exercises
5. Refactor and improve the implementation
6. Apply the concept to a larger project
7. Document what I learned

The goal is not simply to finish a checklist, but to understand **why** a particular approach is used and **when** it should be applied.
